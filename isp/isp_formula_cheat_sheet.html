Camera models★ exam
Perspective projection
x' = f·X/Z, y' = f·Y/Z
Intrinsic matrix K
K = | f_px 0 cx | | 0 f_py cy | | 0 0 1 |
Full projection
p = K [R | t] P_world
f_px = f_mm / pixel_pitch. Homogeneous: divide output by w.
Homography
DOF and correspondences
H is 3×3, 8 DOF (scale-free) Need ≥ 4 point pairs
DLT equation per pair
x' × H x = 0 → 2 eqns per point → 8×9 system
Affine constraint
Last row = [0, 0, 1] → 6 DOF Preserves parallelism
DFT / DCT★ exam
2D DFT forward
F(u,v)= ΣΣ f(m,n) e^{-j2π(um/M+vn/N)}
Conjugate symmetry (real f)
F(u,v) = F*(-u,-v)
Separability
2D DFT = row-wise 1D DFT, then column-wise 1D DFT
Freq → cycles/cm
f_cyc/px = u/N f_cyc/cm = f_cyc/px × (dpi/2.54)
SVD & PCA / KLT★ exam
SVD decomposition
X = U Σ Vᵀ Cols of V = principal components σᵢ² / (n-1) = eigenvalue λᵢ
Rank-k approx (Eckart-Young)
X̂ = Uₖ Σₖ Vₖᵀ ‖X - X̂‖_F² = Σᵢ₌ₖ₊₁ σᵢ²
Pseudoinverse (min-norm)
x̂ = proj of x₀ onto row(A) x̂ = (x₀ᵀr / ‖r‖²)·r
Wiener / MMSE filter★ exam
Spatial domain (MMSE)
Ĥ = R_f Hᵀ(HR_f Hᵀ + R_n)⁻¹
Frequency domain
W(u,v) = H*(u,v)·S_f / (|H|²S_f + S_n)
SNR limits
High SNR → W ≈ 1/H (inverse filter) Low SNR → W ≈ 0 (suppress)
Model: g = Hf + η, f~N(0,R_f), η~N(0,R_n)
MAP estimator & equivalence★ exam
MAP estimator
Ĥ_MAP=(HᵀR_n⁻¹H+R_f⁻¹)⁻¹HᵀR_n⁻¹
Woodbury identity
(A+UCV)⁻¹ = A⁻¹ - A⁻¹U(C⁻¹+VA⁻¹U)⁻¹VA⁻¹
Key result
Ĥ_MMSE = Ĥ_MAP (Gaussian only) Because: posterior Gaussian → mean = mode
Tikhonov regularisation
Regularised inverse filter
F̂(u) = H*(u)·G(u) / (|H(u)|² + λ)
λ role
λ large → smoother, less noise λ small → sharper, noisier λ_opt = σ²_noise / σ²_signal
Motion blur zeros
H = 0 at u = k·N/L, k=±1,±2,... L = blur length in pixels
Histogram equalisation★ exam
CDF-based mapping
pᵣ(k) = nₖ / N T_k = Σⱼ₌₀ᵏ pᵣ(j) (CDF) sₖ = round[(L-1)·Tₖ]
Histogram matching
z = T_target⁻¹(T_input(r)) Equalise both → invert target
L = number of grey levels. Perfect uniformity rarely achieved with discrete images.
Otsu thresholding★ exam
Within-class variance
σ²_W = ω₁σ₁² + ω₂σ₂²
Between-class variance
σ²_B = ω₁ω₂(μ₁ - μ₂)²
Key theorem
σ²_T = σ²_W + σ²_B = constant ∴ min σ²_W ≡ max σ²_B
Sweep t, pick threshold maximising σ²_B.
Conditional expectation & MMSE★ exam
MMSE estimator
ĝ(X) = E[Y|X] minimises E[(Y-g(X))²]
Decomposition
MSE = E[(Y-E[Y|X])²] + E[(E[Y|X]-g(X))²] ↑ irreducible ↑ =0 iff g=E[Y|X]
Orthogonality principle
E[(Y - Ŷ)·h(X)] = 0 for all functions h
Spatial filtering
Local threshold (unsharp style)
d(m,n) = f - (f * h) where h=1/25·ones(5) g = 1 iff d(m,n) > T
Median — noise condition
If k < N/2 pixels corrupted in window: median = true value v (majority wins)
Mean vs median
Mean: linear, low-pass → blurs edges Median: non-linear → preserves edges
Focus measures & PSF
Modified Laplacian
ML = |2f - f(m-1) - f(m+1)| + |2f - f(n-1) - f(n+1)|
Frequency response of ML
H(ω) = 4sin²(ω/2) → high-pass
Defocus PSF & FT
h = 1/(πr²) inside disk radius r H(ρ) = 2J₁(2πrρ)/(2πrρ) (jinc)
Depth from focus: depth = z at max ML across focus stack.
Bilinear interpolation
At fractional location (Δx, Δy)
f(x+Δx, y+Δy) = (1-Δx)(1-Δy)·Q₁₁ + (1-Δx)(Δy) ·Q₁₂ + (Δx)(1-Δy) ·Q₂₁ + (Δx)(Δy) ·Q₂₂
Q's are the 4 integer-coordinate neighbours. Δx=Δy=0.5 → equal-weight average.
HDR & noise models
Linear camera radiance
E = pixel_value / exposure_time Near saturation (p ≈ 255) → unreliable
Noise filter matching
Gaussian noise → mean / Wiener filter Salt-and-pepper → median filter
Hadamard conditions
Well-posed: exists + unique + stable Tikhonov restores stability (condition 3)
K-means & ISODATA
Algorithm
Assign: k*(x) = argminₖ ‖x - cₖ‖ Update: cₖ = mean of assigned points Converge: centres unchanged
ISODATA rules
Split if: σ_within > σ_max AND n > 2N_min Merge if: ‖cᵢ - cⱼ‖ < d_min
K-means = intensity only, spatially blind. Converges to local minimum.
WHT, DCT & energy
WHT property
Hadamard basis: ±1 only → no multiplications needed
DCT energy compaction
Energy packs in LOW frequencies (top-left coefficients in 2D block)
KLT vs DCT
KLT: data-dependent, optimal, slow DCT: fixed basis, near-optimal, fast DCT ≈ KLT for Markov-1, ρ≈0.9
